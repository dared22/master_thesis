# Portfolio risk models to compare

The first three approaches are benchmarks for the proposed joint neural SDE.
For a fair comparison, use the same stocks, portfolio weights, return horizon,
training dates, and evaluation dates for every approach.

| Model | How it works for the stock portfolio | Why include it |
| --- | --- | --- |
| Historical simulation | Apply the portfolio weights at the forecast date to each past day's date-aligned vector of stock returns. Calculate VaR from the resulting historical portfolio losses. | This is an industry baseline. [JPMorganChase's 2025 report](https://www.jpmorganchase.com/content/dam/jpmc/jpmorgan-chase-and-co/investor-relations/documents/annualreport-2025.pdf) describes a historical-simulation framework using the previous 12 months. |
| Weighted historical simulation | Use the same historical scenarios, but give more weight to recent days. | This tests whether a simple response to changing market conditions is enough. [UBS's 2025 report](https://www.ubs.com/content/dam/assets/cc/investor-relations/annual-report/2025/annual-report-ubs-group-2025.pdf) describes an unweighted five-year approach and an exponentially weighted approach for certain legacy positions. |
| Gaussian and Student's *t* copulas | Estimate each stock's return distribution from observed training returns, fit dependence using returns from matching dates, and simulate joint returns. | These are research benchmarks for dependence. The cited bank disclosures establish historical simulation more directly as an industry practice. |
| Joint neural SDE | Fit one multivariate model to the stock-return histories, generate joint return paths, and calculate portfolio losses from those paths. | This is the proposed method whose results will be compared with the benchmarks above. |

The copula benchmarks use return distributions estimated from observed training
data, not distributions generated by the joint neural SDE. If the goal is
one-day VaR forecasting, evaluate each model on later dates using only
information available before each forecast.

The planned shared historical simulation module is specified in the
[historical simulation specification](../../benchmarks/docs/historical-simulation-spec.md).
